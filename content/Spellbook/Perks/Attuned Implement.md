# Attuned Implement \[Perk\] \[Enchantment\]
Rank 1. XP 4. Prerequisite: Enchantment 1.
Choose one of your Affinities. You start each Mission with an Implement attuned to that Affinity. While the Implement is active in one hand and you use a Spell with an effect of the chosen Affinity, reduce its Weave cost by 1 (to a minimum of 1 Weave).
Special: You may gain this Perk any number of times, choosing a new Affinity to gain an Implement for each time.

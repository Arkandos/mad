Formulae are complex effects that are not easily replicated with a Spell. 
# Using Formulae
To use a Formulae you must spend a number of actions, and an amount of Weave or Toughness. Then you must make an Intelligence [[Core Rules|Test]] and achieve a number of successes as required by that Formulae. If you do not achieve the required number of successes, you may spend 1 action to continue trying (record how many successes you have achieved so far this Mission towards that Formulae). If you start using a new Formulae, you lose the "banked" successes for the previous.
A Formulae does not take effect until all costs (including the successes needed) have been paid in full.
# Formulae slots
When preparing for a [[Mission]], choose up to 4 Formulae you have acquired to be your active ones for that Mission. You can only use active Formulae.
*Universal Formulae do not use up a Formulae slot.*
# Formulae relevant keywords

| Keyword         | Short explanation                                                                    |
| --------------- | ------------------------------------------------------------------------------------ |
| [[Delay]] X     | The effect does not happen until X rounds later, in the same phase it was triggered. |
| [[Cooldown ]] X | How many rounds after the Delay that the Formulae can be used again.                 |
| [[Uses]]        | How many times a Formulae can be used before going on cooldown.                      |

# Acquiring new Formulae
Other than the Formulae gained when making a new Mage, you must spend a number of XP equal to a Formulae's Tier and fulfill all other Prerequisites it may have.

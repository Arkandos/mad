# Clawed Transformation \[Formulae\] \[Transmute\] \[Body\] \[Polymorph\]
Tier 2. Rank 1. Prerequisite: Transmute 1, Body 1.
2 actions. 4 Weave. 2 successes. [[Cooldown]] 4.
Melee 1, you or an allied Mage.
Effect: Until the end of the Mission, the target gains the following effects:
Armor & Speed set to 6. The target’s Might becomes 4 if it was lower. The target can no longer wield Weapons other than the following Claws, which they have access to:

Claws \[Weapon\] \[Melee\]
Melee 1, 1d6 Damage, Pierce 3
If you’ve already attacked with this Weapon once this phase, 3d6 damage instead.

The target can end this effect for 1 action.
[[Polymorph]]: A creature can only be affected by one Polymorph at once.

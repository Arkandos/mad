# Action
In the [[Core Rules|Mage Phase]], each mage takes a turn during which they can take 3 actions each.
# Free Action
Can be used at any time, does not use up one of your actions.
## Reactions
Each Mage can use one [[Action types|Reaction]] per round. Only certain effects utilise reactions.

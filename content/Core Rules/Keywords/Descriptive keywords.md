These keywords have no inherent mechanical effect but may still be referenced by other rules.

| Keyword           | Explanation                                                                           |
| ----------------- | ------------------------------------------------------------------------------------- |
| Affinity keywords |                                                                                       |
| Form              | What the magic affects or creates. Examples include Body, Mind, or Fire.              |
| Formulae          |                                                                                       |
| Hex               | Debilitates and controls enemies                                                      |
| Melee             |                                                                                       |
| Modifier          | Modifies a previous part of the Spell                                                 |
| Offensive         | Deals damage or directly impacts the targets                                          |
| Perk              |                                                                                       |
| Ranged            |                                                                                       |
| Support           | Helps you or your allies                                                              |
| Targeting         | Decides what the spell targets                                                        |
| Teamwork          | Has increased effect when used together with another Mage                             |
| Technique         | How the magic interacts with the world. Examples include Create, Destroy, or Perceive |
| Weapon            |                                                                                       |
| Basic             | Descriptor that shows that this effect is cheaper to trigger by other means           |
